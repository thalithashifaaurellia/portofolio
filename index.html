Tentang Saya





Halo, saya Thalitha Shifa Aurellia, mahasiswi Universitas Dian Nuswantoro. Saya masih belajar di bidang teknologi dan belum memiliki keahlian khusus dalam pengembangan web, tetapi saya senang mencoba hal-hal baru dan belajar dari pengalaman.

Salah satu project yang pernah saya kerjakan adalah beautysharing.id, sebuah website yang saya kelola sebagai media berbagi informasi seputar kecantikan dan lifestyle. Dari project ini, saya mulai mengenal bagaimana sebuah website dikelola, bagaimana informasi disusun agar mudah dipahami, serta bagaimana sebuah website dapat dikembangkan dan ditemukan oleh pengguna melalui mesin pencari.


Saya ingin terus keluar dari zona nyaman dan mengembangkan kemampuan di dunia teknologi. Ke depannya, saya tertarik untuk membangun karier sebagai Data Analyst karena saya ingin belajar lebih dalam tentang data dan bagaimana data dapat digunakan untuk menghasilkan informasi yang bermanfaat. Bagi saya, setiap project yang saya kerjakan adalah langkah kecil untuk menambah pengalaman dan mendekatkan diri pada tujuan tersebut.


Halaman web ini dibuat menggunakan HTML5 murni tanpa menggunakan CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan untuk memahami dasar-dasar pengembangan web.
